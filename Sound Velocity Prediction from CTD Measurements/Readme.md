###### \*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\* **BRIEF OVERVIEW** \*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*

The focus of this project is to predict the sound velocity from CTD Measurements. Professionals widely agree that the speed of sound in the seas and oceans significantly impacts the propagation of acoustic waves. This variation can be influenced by ocean properties like temperature, salinity, and pressure, among others. This sparked my curiosity to compare the sound velocity (computed from empirical formulae like UNESCO, Chen and Miller, etc) with the values predicted by machine learning models. 



* Project Title: Sound Velocity Prediction from CTD Measurements
* Data: CTD Measurements, Sound Velocity Profiler (SVP) Data
* Source: GEOMAR Helmholtz Centre (https://doi.pangaea.de/10.1594/PANGAEA.905471),  Sound Velocity Profiler
* Aim: Predict the sound velocity (in water) using ML models
* Models used: Random Forest, XGBoost
